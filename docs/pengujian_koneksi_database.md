# Pengujian Koneksi Database ALTERA

## Tujuan
Memastikan aplikasi ALTERA dapat menggunakan koneksi database untuk proses login dan registrasi.

## Konfigurasi
- Host: localhost
- Database: altera_db
- Driver: PDO MySQL

## Hasil Pengujian

| No. | Pengujian | Hasil |
|---|---|---|
| 1 | Membuka halaman login | Berhasil |
| 2 | Membuka halaman registrasi | Berhasil |
| 3 | Login menggunakan akun uji | Berhasil |
| 4 | Proses registrasi akun uji | Berhasil |

## Kesimpulan
Berdasarkan pengujian, proses login dan registrasi akun uji berhasil dijalankan tanpa error. Hasil ini menunjukkan bahwa koneksi database berfungsi pada alur aplikasi yang diuji.
